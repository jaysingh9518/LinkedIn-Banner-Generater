# 🎨 LinkedIn Banner Generator

A lightweight, interactive client-side web application designed to generate professional, pixel-perfect LinkedIn profile banners (1584 × 396 px) with customizable branding, live preview, and one-click high-resolution PNG export.

Built with an executive layout featuring modern geometric accents, custom brand colors, photo repositioning tools, and corporate styling tailored for leadership and technical roles.

---

## ✨ Features

- **Exact LinkedIn Dimensions:** Renders natively at the official **1584 × 396 px** (4:1 aspect ratio) specifications to prevent cropping or compression artifacts.
- **Real-Time Live Preview:** Responsive canvas with zoom and pan support that updates instantly as you adjust text and layout settings.
- **Photo Customization Controls:**
  - Upload any portrait/headshot.
  - Scale & zoom controls to frame your portrait.
  - Horizontal ($X$) and vertical ($Y$) offset positioning sliders.
- **Dynamic Content Fields:** Edit company name, full name, job title, bio/summary statement, phone number, and LinkedIn URL on the fly.
- **Custom Logo & Vector Graphics:** Pre-configured corporate branding elements, wave motifs, and chevron accents.
- **1-Click High-Res PNG Export:** High-fidelity rasterization using HTML5 Canvas / raster renderers to download a ready-to-upload PNG directly to your device.
- **Zero Backend Required:** 100% client-side application—no server setup, database, or API keys needed.
